Modelo de dados da cruza

Três tabelas guardam a identidade de uma orquídea: taxa (o catálogo, uma árvore), plants (a sua planta) e a nova crosses (o cruzamento). Escolha uma planta de exemplo para ver as linhas de cada tabela, o caminho na árvore e de onde vem a ficha de cultivo.

Como as tabelas se ligam

  1. plants é a planta. Ela é identificada ou por um táxon do catálogo (taxon_id: espécie, grex, gênero…) ou por uma cruza (cross_id), nunca pelos dois. received_name guarda o texto da etiqueta como veio.
  2. crosses é o cruzamento: ♀ semente × ♂ pólen, cada lado um táxon, um texto ou nada (desconhecido), e care_from diz de qual parental vem a ficha. Tem dono (user_id); vazio quer dizer que é do catálogo. Várias plantas podem apontar para a mesma cruza (irmãs).
  3. taxa é o catálogo, uma árvore por parent_id, com a ficha de cultivo. Um grex pode apontar para a sua cruza (cross_id), e é assim que a planta de um grex conhece os parentais.

    Regras que o banco e a API garantem

    banco

    Táxon ou cruza

    plants_determination_ck: no máximo um de taxon_id e cross_id. Grex registrado entra pelo táxon; a cruza é para o que não tem nome no catálogo.

    banco

    Só grex tem cruza

    taxa_cross_rank_ck: taxa.cross_id só em táxon de nível hybrid.

    banco

    Cada lado é uma coisa só

    Táxon ou texto; os dois vazios querem dizer “não sei”, e os dois lados podem ser “não sei”. care_from só aponta para um lado com táxon.

    banco

    Nada some sem aviso

    Toda referência a um táxon usa restrict, inclusive plants.taxon_id. Para tirar um táxon em uso, uma operação futura de fundir táxon repõe as referências.

    api

    Cada um no seu

    A planta só aponta para cruza do próprio dono; o táxon, para cruza do mesmo dono que ele. O catálogo nunca depende de nada pessoal.

    api

    Trocar é trocar

    Mudar a identificação da planta troca a genealogia junto, sem histórico. A cruza que ficou sem nenhuma planta é apagada na mesma operação.

    api

    Sugestão, nunca troca sozinha

    Quando a etiqueta ou um parental em texto bate com um táxon do catálogo, o app oferece a troca; a pessoa decide.
